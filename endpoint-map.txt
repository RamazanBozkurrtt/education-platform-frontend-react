Gateway base URL (docker): http://localhost:8090
Not: Course endpointleri hem /courses/** hem /api/v1/courses/** çalışıyor; frontend için /api/v1/courses/** kullanman daha temiz olur.
Body şemaları
•
RegisterRequest: { email, password(min 6) }
•
AuthenticationRequest: { email, password }
•
RefreshTokenRequest: { refresh_token }
•
ChangePasswordRequest: { oldPassword, newPassword(min 6) }
•
UserProfileRequest: { email?, firstName?, lastName?, headline?, biography?, avatarUrl?, socialLinks? }
•
CourseCreateRequest / CourseUpdateRequest: { title, description, price, categoryId?, learningOutcomes[exactly 4], tags? }
•
LessonCreateRequest / LessonUpdateRequest: { title, summaryTitle(1-2 kelime), videoUrl, duration, orderIndex, completed }
•
EnrollmentCreateRequest: { courseId, userId? } (userId yoksa token’daki user kullanılıyor)
•
InstructorSummariesRequest: { instructorIds: string[] (max 500) }
•
InstructorStatusUpdateRequest: { status: ACTUAL|PENDING|BANNED|DEACTIVATED }
